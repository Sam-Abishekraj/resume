# resume

Sam Abishekraj's portfolio site (SAM-OS v3.0). Live at https://resume-ruddy-omega.vercel.app/

Plain HTML, CSS and vanilla JS with no build step, so Vercel serves it as static files.

- `index.html` – page content
- `assets/css/style.css` – styles (dark theme, terminal windows, scroll sections)
- `assets/js/main.js` – boot screen, typing line, scroll reveals, SutraOps scroll story, counters, contact terminal
- `assets/img/` – profile photo and SutraOps screenshots (WebP)

Run locally: `python3 -m http.server 8000` and open http://localhost:8000
