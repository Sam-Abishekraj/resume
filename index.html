01 Flagship project

      
SutraOps

      
An enterprise integration AI agent for a fictional Indian D2C brand, wired to five business systems through a hand-written Groq tool-calling loop.

      

        View the repo ↗
        Jump to eval results

$ open console

        

      


      
    
        
  1. 
          00 · overview
          
    An agent that works inside the company's systems.
    
          
    SutraOps connects one LLM to a REST CRM/ticketing API, a guarded read-only SQL tool, multilingual RAG over company SOPs, Slack/email notifications and an MCP server. No agent framework: the tool-calling loop is hand-written.
    
          
        
    2. 
        
  2. 
          01 · injection blocked
          
    Hostile text gets redacted before the model reads it.
    
          
    A support ticket hides instructions aimed at the AI. SutraOps flags the tool output, redacts the injected text, and the refund it pushes for still lands in a human approval queue instead of being paid.
    
          
        
    3. 
        
  3. 
          02 · human in the loop
          
    Risky actions wait for a person.
    
          
    Refunds above ₹2,000 and account changes go to an approvals queue that a team lead approves or rejects from the dashboard. The agent is also checked for claiming actions it never actually performed.
    
          
        
    4. 
        
  4. 
          03 · live traces
          
    Every step, accounted for.
    
          
    Each LLM call and tool call is traced with its arguments, results, tokens and latency in a Flask + vanilla JS admin dashboard. Personal data is masked everywhere, and SQL is limited to a whitelist of tables.
    
          
        
    5. 
        
  5. 
          04 · multilingual
          
    English, Tamil and Hindi.
    
          
    Policy questions are answered from the company's SOPs using local embeddings + FAISS, in the language the customer wrote in, with the source document cited.
    
          
        
    6. 
        
  6. 
          05 · built for free-tier limits
          
    Rate limits don't take it down.
    
          
    Runs on Groq gpt-oss-120b with automatic fallback to gpt-oss-20b on rate limits, plus response caching, backoff and a demo replay mode. Notifications land in a mock email/Slack outbox, and guardrail events are logged.
